How to Train with Your Own Dataset

1. Zero Pretrained Weights / Zero YOLO

The CNN is built purely from scratch using 5 custom convolutional blocks + multi-task classification heads for Car Type, Damage Type, and Damage % Regression.

2. Format A: CSV Annotations (Recommended)

Create an annotations.csv file with columns:

image_path,car_class,damage_class,damage_percent
data/images/car1.jpg,Sedan,Dent,25.0
data/images/car2.jpg,SUV,Scratch,12.0
data/images/car3.jpg,Truck,Major Smash,75.0

*Note: damage_percent is optional. If omitted, the model utilizes class severity and Grad-CAM area calculation.

3. Format B: Nested Folders

Place images inside nested directories:

dataset/
  Sedan/
    Scratch/
      img1.jpg
    Dent/
      img2.jpg
  SUV/
    Dent/
      img3.jpg

4. Start Training

Run either of the commands in your terminal:

# Using CSV:
python train.py --data-csv path/to/annotations.csv --epochs 25

# Using Folder Structure:
python train.py --data-dir path/to/dataset_folder --epochs 25

The training pipeline automatically saves models/best_car_damage_cnn.pth and models/classes.json. Restart the dashboard to run on your newly trained weights!
